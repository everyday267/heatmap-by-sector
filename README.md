# 용인시 노선버스 예상 표준운송원가 산출 로직

용인시 노선입찰제(준공영제) 노선에 대해 **운행대수 × 운행일 × 표준단가**를 결합해
노선 단위 **예상 표준운송원가(= 사업자 수령액)**를 항목(인건비·연료비·감가상각비 등)별로
산출하는 Python 모듈 + CLI입니다. 운행대수/차종은 **data.go.kr(TAGO)** 실시간
API로 조회할 수 있습니다.

총액 정산 방식에서는 사업자가 표준운송원가 전액을 받아가므로, 이 값이 곧
**사업자 예상 수령액**입니다.

## 계산식

```
항목별 예상금액 = 표준단가(항목, 차종) × 운행대수(차종) × 운행일수
노선 표준운송원가 합계 = Σ 항목별 예상금액
```

> **용어 주의.** 여기서 나오는 금액은 노선입찰제(총액 정산)에서 사업자가 받아가는
> **표준운송원가 = 사업자 수령액**입니다. 총액 정산 방식에서는 사업자가 표준운송원가
> 전액을 지급받고, 요금 등 운송수입금은 관할관청(용인시)에 귀속되므로 이 결과가 곧
> 사업자 예상 수령액입니다(요금수입을 별도로 차감하지 않습니다).

## 표준단가(표준운송원가) 기준

기준 자료: **2024년 경기도 공공관리제 표준운송원가**(경기교통공사 공개자료).
용인시 조례가 경기도 표준운송원가를 검토·적용할 수 있도록 규정하고 있어, 용인시
자체 용역 수치를 확보하기 전까지 가장 근접한 실무 기준으로 사용합니다.

| 차종 | 총원가(원/대·일) | 인건비 | 연료비 | 감가상각비 |
| :-- | --: | --: | --: | --: |
| 시내대형 | 949,723 | 65.3% | 16.7% | 3.6%(34,470원) |
| 시내중형 | 873,392 | 71.0% | 10.9% | 3.1%(26,800원) |
| 광역 | 973,846 | 63.6% | 14.8% | 5.0%(48,829원) |

문서에 명시된 항목(인건비·연료비·차량감가상각비)은 그대로 고정하고, 나머지 잔여분
(정비비·보험료·기타차량유지비·일반관리비·차고지비·성과이윤)은 문서가 제시한 대표
구성비로 배분합니다. **항목별 단가의 합은 항상 총원가와 정확히 일치**합니다.
자세한 규칙은 [`yongin_revenue/standard_costs.py`](yongin_revenue/standard_costs.py)
docstring 참고.

> 용인시 공식 용역 수치를 확보하면 `standard_costs.py`의 상수(`TOTAL_PER_VEHICLE_DAY`,
> `DOCUMENTED_RATIOS`, `DOCUMENTED_ABSOLUTE`)만 교체하면 됩니다.

pip install -r requirements.txt

## 사용법

### 1) 운행대수를 직접 지정 (API 불필요)

```bash
python -m yongin_revenue.cli --route-no 5001 --vehicle-type 광역 --vehicles 20 --days 30.4
```

### 2) 혼합 차종

```bash
python -m yongin_revenue.cli --route-no 66 --fleet 광역:12 --fleet 시내대형:8 --days 30.4
```

### 3) data.go.kr에서 실시간 운행대수 조회

```bash
export DATAGO_SERVICE_KEY="발급받은_디코딩_인증키"     # .env.example 참고
python -m yongin_revenue.cli --route-no 5001 --city 용인 --days 30.4 --live
```

### 기타 옵션

| 옵션 | 설명 |
| :-- | :-- |
| `--days` | 운행일수 (기본 30.4일 = 월평균). 평일수만 넣으려면 예: `--days 21` |
| `--json` | 결과를 JSON으로 출력 (다른 시스템 연동용) |
| `--basis` | 항목별 정산기준(실비/협약단가/기준단가) 함께 출력 |
| `--list-cities` | TAGO 도시코드 목록 출력 (용인 cityCode 확인) |
| `--route-id` | 검색 결과가 여러 개일 때 특정 TAGO routeId 지정 |
| `--vehicle-type-override` | 실시간 조회 시 차종 자동매핑 결과를 수동으로 덮어씀 |

## data.go.kr 연동 상세

- 인증키: [공공데이터포털](https://www.data.go.kr)에서 **국토교통부 TAGO
  버스노선정보/버스위치정보** 활용신청 후, **Decoding 키**를 `DATAGO_SERVICE_KEY`에 설정.
- 사용 API: `getCtyCodeList`(도시코드), `getRouteNoList`(노선검색·차종),
  `getRouteAcctoBusLcList`(실시간 버스위치→운행대수).
- **운행대수 주의:** 실시간 위치 API는 *호출 시점에 운행 중인 차량*만 반환하므로
  차고지 대기 차량이 빠진 **관측 최소값**입니다. 정확한 인가대수는 여러 시간대
  샘플링의 최대값을 쓰거나, `--vehicles`로 용인시청 인가대수를 직접 지정하세요.
